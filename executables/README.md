# Moon Dancer executables

Ready-to-install packages are generated automatically by GitHub Actions and attached to each GitHub Release.

## Windows

- `Moon Dancer_*_x64-setup.exe` — recommended installer for most users.
- `Moon Dancer_*_x64_en-US.msi` — MSI package for managed installations.

## Linux

- `moon-dancer_*.AppImage` — portable package. Mark it as executable and open it.
- `moon-dancer_*_amd64.deb` — package for Debian, Ubuntu, Linux Mint, and compatible distributions.

The generated files are intentionally not committed to Git because installers are large. Download them from the repository's **Releases** page. Local builds can be copied into the platform folders below.
