# Moon Dancer for Windows

## Download

**[Open the latest official Release](https://github.com/Aykolin/moon-dancer/releases/latest)**

Choose one of the following assets:

- `Moon Dancer_*_x64-setup.exe` — recommended for most Windows users.
- `Moon Dancer_*_x64_en-US.msi` — intended for managed or administrative installations.

## Installation

1. Download the `.exe` installer from the latest Release.
2. Close any previous Moon Dancer window and fully exit the desktop mascot.
3. Open the downloaded installer and follow the Windows prompts.
4. Launch Moon Dancer from the Start menu or desktop shortcut.

Local test builds are unsigned. Windows SmartScreen may display a warning for an unsigned local package. Official downloads should always come from the repository owned by [Aykolin](https://github.com/Aykolin/moon-dancer).

Installer binaries are excluded from Git and remain attached to their versioned Release.
