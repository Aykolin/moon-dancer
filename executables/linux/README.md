# Moon Dancer for Linux

## Download

**[Open the latest official Release](https://github.com/Aykolin/moon-dancer/releases/latest)**

Choose the package that matches your system:

- `moon-dancer_*.AppImage` — portable package for most modern Linux distributions.
- `moon-dancer_*_amd64.deb` — installer for Debian, Ubuntu, Linux Mint, and compatible distributions.

## AppImage

Make the downloaded file executable and run it:

```bash
chmod +x moon-dancer_*.AppImage
./moon-dancer_*.AppImage
```

## Debian package

Install the downloaded package with:

```bash
sudo apt install ./moon-dancer_*_amd64.deb
```

Package files are excluded from Git and remain attached to their versioned Release.
